Key Observations

What's Working

  • Condensed reasoning preserves the original voice. Unlike v1 (which produced a clean numbered list that read like a different model), v2 keeps the exact phrasing — "We need to produce...", "Let's craft 2 items", "She smashes a quarter of...". The student model will see thinking patterns close to what it would naturally produce.
  • Compression targets the right things. The model removes meta-commentary ("We need to ensure JSON is valid"), format second-guessing ("But we need to show step by step... Probably that's fine"), and repeated restatements of the same requirement — while keeping the actual planning and computation.
  • Best-of-N selection catches real quality differences. In Example 1, temp=0.5 beat temp=0.3 — the mid-temperature generation had better schema compliance despite the low-temperature one being "more careful".
  • Math correctness is verifiable. The gold answer matching works — Gemma4 confirmed the student's 112 was correct.

Trade-offs vs v1

  • Less compression (53% vs 83%). Keeping the original voice means more tokens survive. This is the right trade-off — activation matching matters more than token savings.
  • Longer scoring time (56s avg vs 16s). More tokens in the condensed output means the teacher generates more per prompt. For ~3,900 prompts: ~61 hours (vs ~17h for v1). Consider turning thinking off for ranking (not condensation) to cut this.
  • YAML output issue persists. Gen 0 won even though it output JSON instead of YAML. Gemma4 noted this but still ranked it highest. For strict format training, we may need format validation in the scoring loop.
