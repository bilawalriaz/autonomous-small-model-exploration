Key Observations

What's Working

  • Reasoning condensation is dramatically better than regex stripping. The teacher removes "oh wait", self-corrections, and dead-end planning while preserving the actual reasoning structure. The 88% compression on the 5,479-char example is much more useful than the brute-force 63% that compress_aggressive.py achieved — and the condensed version is actually better reasoning, not just shorter.
  • Best-of-N selection catches real quality differences. In Example 1, temp=0.5 beat temp=0.3 — the mid-temperature generation had better schema compliance despite the low-temperature one being "more careful". The teacher noticed.
  • The condensed reasoning reads like a clean thinking trace. Numbered steps, no fluff, same technical voice. This is exactly what we'd want the student to learn.
  • Math correctness is verifiable. The gold answer matching works — Gemma4 confirmed the student's 112 was correct.

Concerns to Watch

  • YAML output actually came back as JSON. Gen 0 won even though it output JSON instead of YAML. Gemma4 noted this but still ranked it highest. For strict format training, we may need format validation in the scoring loop.
  • Only 1 generation available for the GSM8K prompt. The deck's remaining prompts had fewer gens. Best-of-1 is just "take whatever we have" — no ranking value.
  • ~16s average scoring time. With thinking on, each prompt takes 10-28s. For 3,900 prompts: ~17 hours. Consider whether turning thinking off for ranking (not condensation) would speed things up without losing quality.
