# S02 — MiniCPM5-1B structurally diverse Stage 0 measurement repair

## Hypothesis

H-MiniCPM-single-shot: the narrow S01 schema/concise effect persists when
evaluation task structures are held out from the generated training families
and a token-shingle near-duplicate audit has no cross-split violations.

## Method

Replace S01's repetitive generated schema and concise-instruction held-outs
with structurally distinct deterministic families. Retain source-disjoint
GSM8K-test math and MBPP-test code. Build a versioned manifest with exact and
5-token-shingle Jaccard near-duplicate checks across train/validation/heldout.
Only after the data audit passes, evaluate Q4 base and corrected merge using
the M02 harness and S01 deterministic score path.

## Seeds

Pilot — deterministic seed-42 Q4 baseline only; no training. Follow-on SFT
requires seeds 42, 137, and 2026.

## Metrics to collect

- Per-split source/license/revision/count; exact and near-duplicate audit.
- Fixture validation, output integrity, per-family paired rates, wins/losses/
  ties, and 20,000-resample paired bootstrap CIs.

## Expected result

Zero cross-split exact or near-duplicate violations; all evaluators pass; any
schema or instruction gain remains positive on structurally held-out tasks.

## Falsification criteria

Reject S02 data admission if the audit finds cross-split near duplicates,
fixtures fail, evaluator integrity fails, or source test rows enter training.
Do not claim transfer if target CIs include zero.

## Estimated compute time

About 1–2 hours for 1,600 Q4 generations after the CPU audit.

## Dependencies

M01/M02, S01 v2 narrow baseline, and S01's documented prompt ambiguity.
