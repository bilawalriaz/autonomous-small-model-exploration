# S01 — MiniCPM5-1B Stage 0 data admission and frozen single-shot baseline

## Hypothesis

H1/H3/H4/H6 (MiniCPM single-shot adaptation): a versioned, leakage-audited
training corpus and deterministic 200-example-per-family suite can measure
math, strict structured-output, concise instruction, and executable-code
behavior without a model-based judge.  This experiment does **not** test a
training effect; it establishes the pre-training decision boundary.

## Method

Build source manifests and normalized exact/near-duplicate indexes before
splitting.  Admit GSM8K-train math rows only after answer extraction, strict
JSON/YAML/schema rows only after deterministic validation, concise replay rows
with retained provenance, and code rows only after their supplied test passes.
Freeze separate train/validation/held-out manifests.  Build 200 deterministic
held-out examples each for math, schema, concise instruction following, and
executable Python.  Validate every evaluator against fixtures, then evaluate
the corrected Q4 base and corrected direct merge with M02's greedy GGUF
harness.  Score with deterministic validators and paired 20,000-resample
bootstrap confidence intervals; export a stratified manual-review sample.

## Seeds

Pilot — deterministic Q4 decoding (seed 42), justified because no training or
stochastic selection occurs.  Any follow-on SFT experiment uses seeds 42, 137,
and 2026.

## Metrics to collect

- Manifest counts, source revisions/licenses, and normalized duplicate/
  near-duplicate intersections across all splits.
- Fixture pass counts and evaluator/version hashes.
- Per-family exact score, paired wins/losses/ties, 20,000-bootstrap 95% CI,
  output-boundary integrity counts, and a stratified raw-output review sample.

## Expected result

All four suites contain at least 200 valid held-out examples, no cross-split
duplicate hashes, all fixtures pass, and both Q4 models complete all examples
without output-boundary failures.  Behavioral differences are descriptive
baseline measurements only.

## Falsification criteria

Do not admit the corpus or report behavioral metrics if a source license or
revision is missing, a cross-split duplicate remains, a deterministic
validator/fixture fails, a benchmark test row appears in training, or GGUF
output-boundary integrity fails.

## Estimated compute time

About 3–6 hours of single Q4 inference on aero (1,600 model generations),
plus CPU data construction and validation.

## Dependencies on prior experiments

M01 corrected RS-LoRA merge equivalence, M02 GGUF boundary validation, and M03
pilot result.  No training starts unless S01 data and evaluator admission pass.
