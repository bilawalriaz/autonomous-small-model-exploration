# M03 — Corrected MiniCPM5-1B Q4 paired held-out evaluation

## Hypothesis

After correcting RS-LoRA scaling, the fixed 1.0 math / 0.7 formatting direct
merge improves its target tasks over the Q4 base without violating pre-registered
code and tool-format regression gates.

## Method

Evaluate base and corrected direct merge on the same frozen held-out set with
the M02 deterministic GGUF harness. Programmatic scorers assess arithmetic
exactness, JSON/schema validity, Python snippet output, and XML tool-call
format. Report paired deltas, win/loss/tie counts, and paired bootstrap 95% CIs.

## Seeds

Pilot — deterministic Q4 decoding at seed 42; no new training. This can only
decide whether to proceed to three-seed *training* experiments, not establish
general capability or adapter synergy.

## Metrics to collect

- Per-example binary scores and raw outputs for all four task families.
- Paired model delta with 20,000 paired bootstrap resamples and 95% CI.
- Target and control score rates, paired win/loss/tie counts.
- Prompt echo/template residue/subprocess-failure counts from M02 fields.

## Expected result

Math and JSON deltas have positive lower confidence bounds; code and tool
control deltas stay above the -10 percentage-point regression budget.

## Falsification criteria

Do not call the merge beneficial if either target lower bound is non-positive,
if any control lower bound is below -10pp, if extraction-integrity checks fail,
or if results depend on non-programmatic/mock judging.

## Estimated compute time

10–20 minutes on aero for 160 Q4 generations and aggregation.

## Dependencies on prior experiments

M01 merge equivalence and M02 GGUF boundary validation.
